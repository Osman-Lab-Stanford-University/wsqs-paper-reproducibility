# Reproducibility materials

The repository documents the original-study computational workflow and presents verified aggregate outcomes for the N = 6,039 analytical cohort.

| Study component | Materials |
| --- | --- |
| Measurement and predictor construction | Scoring code, survey-variable manifests, response coding and unit tests |
| Forecasting and learner comparisons | Seven S/C/P predictor-block models, ten matched splits, benchmark model comparisons |
| Attribution and inference | Three-block R² Shapley allocation, SHAP values summarized by block and feature, priority-null B1000 analyses |
| Service-response relationships | Four severity-response profiles with 200 development-refit bootstrap intervals |
| Measurement structure | CORE-8 score summaries, weighting comparisons, Cronbach alpha and 30-item exploratory factors |
| Study coverage | S4 household demographics, provider/source distributions, geographic matches and settlement classifications |
| Manuscript exhibits | Tables 1–8 and 56-exhibit dependency register with corresponding numerical sources |
| Synthetic execution | 25-record demonstration plus reproducibility tests |

The observed analytical dataset is held in the authorized study environment. Public files contain documented procedures, aggregate results and synthetic records. The associated access instructions are in [`docs/DATA_AVAILABILITY.md`](docs/DATA_AVAILABILITY.md).
