# Stage code and input contracts

The source scripts are the analysis-stage computations, not a new statistical model. They use the historical Mac working path as the default and validate the frozen N=6,039 cohort and expected aggregate totals. Use explicit authorized paths when moving the module to the existing reproducibility-package environment.

For a full input-level rerun, execute 01, 02, 03 then 04 using its private Stage 4 geographic input. Execute 05 after the publication-stage S31 draft exists. The results in `../results/` are the verified aggregate outputs of the coverage workflows. The separately managed manuscript graphics are not part of these source scripts.

Outputs must be reviewed against `EXPECTED_AGGREGATES_N6039.json`. No original survey workbook or existing reproducibility package is written by these scripts.
